# BloodBridge – Sample Dataset

This folder contains sample data used for developing and testing the BloodBridge application.

The dataset consists of fictional records representing donors, hospitals, blood requests, and donor responses.

## Files Included

- **donors.json:** Contains sample donor profiles, including blood groups, locations, availability, and verification status.
- **hospitals.json:** Contains sample hospital information and verification status.
- **blood-requests.json:** Contains sample blood requests with required blood groups, units, locations, urgency levels, and request statuses.
- **donor-responses.json:** Contains sample donor responses to hospital blood requests, including accepted and declined requests.

## Purpose

This dataset is used to test the donor matching system based on blood group compatibility, location, availability, and profile verification.

## Important Note

All records are fictional and created exclusively for development and testing purposes. They do not represent real donors, hospitals, or actual blood requirements.

The system only identifies potential donors. Final medical eligibility and transfusion compatibility must be determined by qualified hospital or blood-bank professionals.
