BloodBridge sample data

All records in this folder are fictional synthetic records created only for local development and testing.
They are NOT real donors, hospitals, contact details, or live availability information.
Do not use this data to contact anyone or coordinate an actual donation.

Files:
- donors.json: fictional donor profiles
- hospitals.json: fictional hospital profiles
- blood-requests.json: fictional blood requests
- donor-responses.json: fictional donor responses

The coordinates are approximate test coordinates around the named towns, not actual donor locations.
Blood group matching in this demo is only a preliminary search filter. Actual transfusion compatibility,
medical eligibility, crossmatching, and donation decisions must be determined by qualified hospital/blood-bank staff.
